🛡️ TRUSTLAYER Guardian — Settings

Configure your backend connection and authentication. Settings are stored locally in Chrome.

⚠️ Token storage notice: Your JWT or backend token is stored in chrome.storage.local on this device only. It is not synced to other devices, not visible to other extensions, and not sent anywhere except your configured backend URL. Clear it here when no longer needed.

Backend Connection

Use http://localhost:8000 for local development. Use https://your-backend.example.com for a deployed instance. The WebSocket will automatically use ws:// or wss://.

Leave blank when running locally without authentication (dev mode). Never paste DETECTIF_API_KEY or JWT_SECRET_KEY here — only paste the short-lived user JWT issued by your backend's /api/v1/auth/token endpoint, or the BACKEND_ACCESS_TOKEN value from your .env file for local dev.


Authentication modes supported:
  • Dev open (no auth): No token required when backend runs locally without BACKEND_ACCESS_TOKEN or JWT_SECRET_KEY.
  • JWT: Paste the JWT returned by POST /api/v1/auth/token.
  • Shared token: Paste the value of BACKEND_ACCESS_TOKEN from your backend .env.

The token is sent in the WebSocket's first JSON frame as {"type":"auth","token":"…"} — never in URL query parameters.
